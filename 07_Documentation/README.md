# ISYouth Worship App 🎸

## Descriere
Aplicație mobilă pentru planificarea și organizarea programelor de worship ale echipei **ISYouth Worship**.

## Caracteristici principale
- 🎵 **Setlist Builder** - Creează programe drag-and-drop
- 📋 **Management programe** - Planificare pe săptămâni/luni
- 🎸 **Repertoriu** - Catalog cântări cu acorduri și versuri
- 👥 **Echipă** - Management membri și roluri
- 📱 **Live Mode** - Versuri fullscreen în timpul serviciului
- 🔔 **Notificări** - Alertări pentru echipă
- 📊 **Statistici** - Raportare și analiză

## Tehnologie
- **Frontend:** Flutter 3.x (Android + iOS)
- **Backend:** Firebase (Firestore, Auth, Storage)
- **Real-time:** WebSocket pentru Live Mode
- **State Management:** Provider

## Cum să începi
1. Instalează Flutter SDK: https://flutter.dev/docs/get-started/install
2. Clonează sau copiază folderul `05_Flutter_Project_Template/`
3. Adaugă fonturile Inter în `assets/fonts/`
4. Configurează Firebase (vezi `03_Database_Schema/`)
5. Rulează: `flutter run`
